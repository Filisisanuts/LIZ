# 店铺经营管理系统

单页经营管理系统，覆盖日报、采购、费用、库存、报表等全流程，支持本地存储、Supabase 云同步与用户登录。

## 项目结构

```
├── index.html              主入口（HTML结构 + 外部引用）
├── login.html              登录/注册页
├── dashboard.html          只读报表页（无需登录）
├── css/
│   └── style.css           全局样式（变量、布局、组件、响应式、报表左右布局）
└── js/
    ├── config.js            数据库定义、存储键名、导航配置、设置同步
    ├── utils.js             工具函数（日期、格式化、弹窗、Toast、图片压缩、日期/月份选择器）
    ├── category.js          采购分类管理（区域分类、下拉联动、自定义输入）
    ├── search.js            全局搜索（日报/采购/仓库/费用，防抖模糊匹配）
    ├── nav.js               页面路由、侧边栏渲染、悬浮导航栏、页面切换
    ├── auth.js              用户认证（登录/注册/登出、游客模式、登录弹窗）
    ├── dashboard.js         总览仪表盘（昨日日报、月累计、采购成本、贵重物品、7日趋势图）
    ├── daily.js             日报录入（营收、外卖、客流、自由行、备注）
    ├── purchase.js          采购管理（手动录入、AI拍照识别、日历视图、退货）
    ├── expense.js           费用管理（记录、分类、照片附件）
    ├── inventory.js         贵重物品库存（茗茶/香烟/酒类/其他，简单成本计算、入库/销售、退货、月度结转、明细）
    ├── warehouse.js         仓库管理（通用物资库存、安全库存预警）

    ├── report.js            报表（利润表、营收、成本、毛利、每日营收、客情包厢，左右布局）
    ├── brief.js             汇报生成（AI辅助生成经营汇报文本）

    └── app.js               应用初始化（启动流程、工具栏渲染、店铺名动态显示、Chart.js 加载）
```

## 用户认证

基于 Supabase Auth，支持邮箱/密码注册与登录。

- **未登录**：可浏览总览、报表等只读页面，不可录入或修改数据。尝试写操作时自动弹出登录框
- **游客模式**（`?guest=1`）：可查看但不可编辑，页面顶部显示提示条，设置页隐藏危险操作按钮
- **已登录**：完整读写权限，数据绑定当前账号
- **忘记密码**：登录页提供密码重置功能，通过 Supabase 发送重置邮件
- **入口**：导航栏右侧头像/👤图标，或设置页「用户账号」区域

## 店铺信息

在设置页可编辑店铺名称、图标（8个预设 emoji + 自定义）和副标题（默认 COFFEE），存储在 `DB.settings` 并云端同步。动态显示在页面标题、侧边栏、导航栏、登录弹窗、报表和汇报页。

## 数据同步

- Supabase 凭证内置在 `sync.js`，无需手动配置
- 每次保存同时写入用户行（`用户ID`）和共享行（`shop_data`）
- dashboard.html 从共享行读取，无需登录即可查看
- 所有设置（字体/字号/主题/MiMo配置等）也随云端同步

## 贵重物品库存

系统支持4种库存类别，各有独立的物品管理、入库/销售记录和结存计算：

| 类别 | 计算模式 | 说明 |
|------|---------|------|
| 茗茶 | 按克/按包（可切换） | 按杯/壶消耗，支持克/包两种模式 |
| 香烟 | 按包 | 简单模式，按包买卖 |
| 酒类 | 按瓶 | 简单模式，按瓶买卖 |
| 其他贵重物品 | 可选（简单/按克/按包） | 创建时选择计算方式 |

- **退货处理**：采购退货以负数 qty 存储，`invCalc` 自动扣减结存
- **月度结转**：跨月时自动触发，所有库存商品逐个弹窗确认结存数量，可编辑后写入下月期初
- **结存计算**：简单公式 `当月期初 + 当月入库 - 当月销售`
- **成本计算**：简单公式 `销售数量 × 单位成本`
  - 茗茶：`售出杯数×每杯成本 + 售出壶数×每壶成本`
  - 香烟/酒类：`销售数量 × 单位成本`

## 独立报表页

`dashboard.html` 是独立的只读报表页面，无需登录，直接从 Supabase 读取数据。包含6个标签页：

| 标签 | 内容 |
|------|------|
| 利润表 | 左表格 + 右柱状图 |
| 营收总表 | 左两个表格（收入分类+支付渠道）+ 右两个饼图 |
| 每日实收 | 左每日明细表 + 右折线柱状混合图 |
| 客情包厢 | 左每日客情表 + 右折线柱状混合图 |
| 成本费用 | 左采购/费用分类表 + 右两个图表 |
| 采购明细 | 日历视图，点击日期查看详情弹窗 |

设置页「分享报表」区块提供一键复制链接功能。

报表使用 `.rep-grid` 左右布局，桌面端数据表和图表并排显示，768px 以下移动端自动切换为上下排列。每日营收和客情包厢使用 `.rep-grid-wide` 宽表格比例（约6:4），确保多列表格在桌面端有足够宽度。

## 本地运行

直接用浏览器打开 `index.html` 即可，无需构建步骤。如需本地服务器：

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```

## 数据存储

- **本地**：`localStorage`，键名 `ax_cafe_v8`
- **云端**：Supabase 表 `cafe_data`，每用户独立行 + 共享行 `shop_data`
- **认证**：Supabase Auth，会话自动持久化
- **设置同步**：字体/字号/主题/MiMo配置/店铺信息等存入 `DB.settings` 云端同步
- **离线同步**：Base64 编码的完整数据库 JSON，通过同步码手动迁移

## 维护说明

- CSS 文件通过 `style.css?v=版本号` 控制缓存，每次修改 CSS 后递增版本号即可强制浏览器刷新
- JS 模块修改后上传即生效，无需额外操作
- 新增模块时在 `index.html` 中按依赖顺序添加 `<script>` 引用
