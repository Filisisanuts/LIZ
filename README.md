# 店铺经营管理系统

单页经营管理系统，覆盖日报、采购、费用、库存、报表等全流程，支持本地存储、Supabase 云同步与用户登录。

## 功能模块

### 模块分组

```
📊 日常经营
├── 总览（始终启用）
├── 日报
├── 采购
└── 费用

💎 贵重物品
├── 茗茶
├── 香烟
├── 酒类
└── 其他贵重物品（支持自定义）

📦 仓库管理
├── 仓库
└── 报损

📈 数据分析
├── 报表
└── 汇报
```

### 配置系统

系统支持用户自定义配置，每个账号独立存储：

| 配置项 | 说明 |
|--------|------|
| 日报标签 | 自定义经营数据标签 |
| 日报功能 | 包厢预定、汇报人（可选） |
| 采购配置 | 来源、区域、分类（层级配置） |
| 费用分类 | 自定义费用分类 |
| 仓库分类 | 自定义仓库分类 |
| 贵重物品 | 预设类型 + 自定义类型 |

### 新手引导

首次使用时进入引导页面，帮助用户完成基础配置：

1. 功能模块选择（分组显示）
2. 日报标签配置
3. 日报功能配置
4. 采购配置（来源、区域、分类）
5. 费用分类配置
6. 仓库分类配置
7. 完成

## 用户认证

基于 Supabase Auth，支持邮箱/密码注册与登录。

- **未登录**：可浏览总览、报表等只读页面，不可录入或修改数据
- **游客模式**（`?guest=1`）：可查看但不可编辑
- **已登录**：完整读写权限，数据绑定当前账号

## 店铺信息

在设置页可编辑店铺名称、图标和副标题，存储在 `DB.settings` 并云端同步。

## 数据同步

- Supabase 凭证内置在 `sync.js`，无需手动配置
- 每次保存同时写入用户行和共享行
- dashboard.html 从共享行读取，无需登录即可查看
- 配置跟随用户账号，每个账号独立存储

## 贵重物品库存

系统支持多种库存类别，各有独立的物品管理、入库/销售记录和结存计算：

| 类别 | 计算模式 | 说明 |
|------|---------|------|
| 茗茶 | 按克/按包 | 按杯/壶消耗 |
| 香烟 | 按包 | 按包买卖 |
| 酒类 | 按瓶 | 按瓶买卖 |
| 其他 | 可选 | 支持自定义类型 |

- **退货处理**：采购退货以负数存储，自动扣减结存
- **月度结转**：跨月时自动触发，确认结存数量
- **自定义类型**：支持添加任意贵重物品类型

## 开发指南

### 环境要求

- Node.js 18+
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

访问 http://localhost:5173/

### 构建生产版本

```bash
npm run build
```

产物在 `dist/` 目录。

### 本地运行（旧系统）

直接用浏览器打开 `index.html` 即可，无需构建。

## 测试数据

测试数据集位于 `tests/fixtures/`，包含：

- 日报数据
- 采购记录
- 费用记录
- 库存数据（茗茶/香烟/酒类/其他）
- 预期计算结果

## 部署

### 开发环境

```bash
npm run dev
```

### 生产环境

```bash
npm run build
# 将 dist/ 目录部署到 Web 服务器
```
