## 2026-09-14

### 重构实施

**目标**：将现有系统从无构建步骤的静态站点，渐进重构为可构建、可测试、可维护的前端工程。

**完成内容**：

#### 1. Vite + TypeScript 骨架
- 初始化 Vite 项目
- 配置 TypeScript
- 建立 CSS 分层体系（tokens/base/layout/utilities）

#### 2. 新架构目录
- `src/app/` - 应用壳、路由、状态
- `src/features/` - 业务模块（9个）
- `src/shared/` - 共享工具
- `src/legacy/` - 旧系统桥接层

#### 3. 配置管理系统
- 创建 `config-manager.ts` 统一配置管理
- 支持用户级别配置（每个账号独立）
- 配置项：日报标签、采购分类、费用分类、仓库分类、贵重物品类型

#### 4. 新手引导
- 创建 `onboarding.html` 引导页面
- 分组选择功能模块（日常经营/贵重物品/仓库管理/数据分析）
- 支持回车添加、拖拽排序
- 配置跟随用户账号

#### 5. 侧边栏动态生成
- 根据配置动态显示/隐藏模块
- 兼容旧用户（无配置显示所有）
- 模块分组显示，带分隔符

#### 6. 日报页面条件渲染
- 根据配置显示/隐藏销售区块
- 支持包厢预定和汇报人（可选）
- 自定义贵重物品类型支持

**修改文件**：
- `onboarding.html` - 新手引导页面
- `src/main.ts` - 新架构入口
- `src/app/` - 应用壳、路由、状态

- `src/shared/config/config-manager.ts` - 配置管理
- `src/shared/onboarding/onboarding-page.ts` - 引导组件
- `src/shared/format/currency.ts` - 格式化工具
