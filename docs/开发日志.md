## 2026-09-26（工资表头分组与公式引擎）

### 工资字段体系：分组配置化 + 账号级公式

**目标**：工资表表头按「信息项 / 应发项 / 扣款项」结构化展示（对齐原版 Excel 工资表双行合并表头），字段与分组全部配置化，计算公式可编辑且仅对当前账号生效。

**完成内容**：

- 表头分组配置化：新增 `salaryFieldGroups`（默认 8 组：信息项、应付基本工资项目、提成绩效、应付小计、单位代扣个人缴费部分、应付总计、代扣代缴项目、实发工资），每个字段挂 `group` 归属；出勤天数按 Excel 归入「应付基本工资项目」组。老配置自动迁移；用户删除且无字段引用的分组不会被复活。
- 双行分组表头：`salaryTableHeaderHtml()` 动态生成——普通分组第一行 `colspan` 分组标题 + 第二行字段名，span 分组字段 `rowspan=2` 跨行；顺带修复部门标题行少 1 格的错位 bug。
- 「工资字段设置」弹窗分组管理：分组可增删改名/排序/跨行开关，字段行可选所属分组；新自定义字段默认未分组，**保存前必须配置**（校验拦截）。
- 固定表头：工资表改为 `.salary-table-wrap` 框内横竖滚动（`overflow-x` 容器内 sticky top 对视口失效，改走容器内滚动，效果对齐 Excel），两行表头 sticky 钉框顶（行1 top:0 / 行2 top:36px）；工具栏（月份 + 添加/导入）移除 sticky 随内容滚动。修复 `thead th` 缺 z-index 被数据行覆盖的层叠问题。
- 账号级公式引擎（`nav.js`）：分词 + 递归下降解析 + 求值，白名单函数 `EARNINGS() DEDUCTIONS() DIRECT() PRE_TAX() POST_TAX() SUM ROUND MIN MAX`，支持 `+ - * /`、括号与 `{字段}` 引用，不使用 eval。公式保存在 `salaryFieldDefinitions[].formula`（存字段 id，UI 显示字段名，重命名不断链），随账号配置云端同步，**每个账号独立**。
- 默认公式与旧计算逻辑数值等价（含 `应付合计/31×出勤天数`），迁移无感；求值失败/循环引用回退内置计算，表格不中断。
- 弹窗改三标签页（表头分组 / 工资字段 / 计算公式）：公式页逐个编辑 6 个计算字段，支持插入字段下拉、就近错误提示、可用函数说明；保存时三重校验（语法错误、未知字段、循环引用）均拦截。
- 审查补漏：旧账号工资字段按新版默认顺序迁移，避免新增字段插入旧序号后拆散分组；信息项保留数值类型，出勤天数缺失时迁移为 31、明确填写 0 时保持 0。
- 计算语义对齐原 Excel：`应付总计 = 应付小计 - 社保`、`应扣合计 = 个税等代扣代缴项`、`实发工资 = 应付总计 - 应扣合计`；字段的应发/扣款归属会同步更新计算组。
- 补充真实双层工资表头导入回归测试，覆盖部门、姓名、职务、卡号、出勤、社保、个税及小计行过滤；保存工资前会物化自动计算字段及兼容汇总字段。
- 工资字段设置弹窗改为固定头尾、中央滚动的紧凑结构；分组项和字段项改为列表布局，“跨行显示”改为“单列显示”，保存按钮始终可见。
- Excel 导入完整链路：添加菜单拆分为「单独添加员工 / Excel 工资表批量识别」；识别后先弹预览（已识别 N 位员工），合并模式按「姓名 + 部门 + 职务」匹配更新（保留 id/employeeId）、覆盖模式整表替换；公式引擎新增 `BASE()`（基本工资项目组求和，应付合计默认公式简化为 `BASE()`）；字段结构迁移由 `salaryFieldSchemaVersion`（当前 v2）控制，仅在升级时执行一次。
