# Ax-Coffee 测试说明

## 自动化测试

在修改代码后，可以使用这个测试脚本来验证修改是否正常工作。

### 测试脚本功能

- 启动本地服务器（端口 8080）
- 检查页面是否正常加载
- 验证基本功能
- 生成截图供检查

### 如何运行测试

**方法1：手动启动服务器 + 运行测试**
```bash
# 进入项目目录
cd D:/ax-coffee

# 启动服务器
python -m http.server 8080 &

# 运行测试
python test_app.py
```

**方法2：一键启动（推荐）**
```bash
cd D:/ax-coffee
python -m http.server 8080 & sleep 2 && python test_app.py
```

### 测试输出

- 通过：`✓ 基本页面测试通过`
- 失败：会显示具体错误信息
- 截图：保存在 `test_screenshot.png`，可查看页面实际效果

### 测试后清理

```bash
# 停止服务器
kill $(lsof -t -i:8080) 2>/dev/null || true
```

### 在 Claude 中测试

如果用 Claude 代码助手修改后，Claude 会自动：
1. 修改相关文件
2. 运行测试脚本
3. 检查测试结果
4. 如果有问题，立即修复

## 手动测试检查清单

每次修改后，需要检查：

- [ ] 页面正常加载
- [ ] 没有 JavaScript 报错（打开浏览器控制台）
- [ ] 修改的功能正常工作
- [ ] 样式显示正常
- [ ] 响应式布局在手机、平板、桌面都正常
- [ ] localStorage 数据读写正常
- [ ] 与其他功能没有冲突
